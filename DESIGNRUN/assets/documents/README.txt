DESIGNRUN — assets/documents folder
===================================

Place real, company-approved files in this folder. The website only shows
working download buttons when a file listed below actually exists.

Files currently included (safe demo files):
  1. designrun-brochure.html
     - A printable sample brochure (HTML). Open it and use your browser's
       Print -> Save as PDF option to create a PDF version.
     - Replace this file with your real PDF brochure if you have one.
       If you add a PDF, update the file name in js/storage.js (DR.documents).

  2. demo-report-template.html
     - A DEMO template only. It is NOT an engineering report, approval,
       certificate, or safety document.

Rules for this project:
  - Never place confidential client data here. This is a static frontend demo.
  - Never present a demo file as a real engineering deliverable.
  - Real structural analysis results must come from validated engineering
     software, the relevant design codes, and qualified professional review.

Supported static files: .pdf, .html, .csv, .xlsx, .docx, .dwg, .zip, images.
