# Designrun

Designrun is a small sprint-planning dashboard for creative teams. It keeps a lightweight backlog of tasks, supports quick completion toggles, and provides a simple summary of work remaining.

## Features

- Add tasks with title, assignee, estimate, priority, and status.
- Toggle completion states directly from the board.
- Archive finished work in one click.
- View a compact summary for total work, active items, and priority focus.

## Run locally

```bash
npm install
npm start
```

Then open http://localhost:3000.

## Test

```bash
npm test
```
